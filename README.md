# Make 24 · 24点

The classic card game: make 24 from four cards with + − × ÷ and brackets, using every card exactly once.
The phone reads the cards out loud and listens to your answer.

Plain HTML/CSS/JS, no build step. Tests: `npm install`, then `npm test` (see `tests/README.md`).
Changes reach Test and Production only through the release loop; nothing is pushed by hand.
